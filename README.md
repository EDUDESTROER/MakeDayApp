# Back-end Security Enhancements & Hardening

- IPv6 Bypass Prevention
- Progressive Login Slow Down
- CSRF Protection
- Advanced Rate Limiting with `express-rate-limit`
- Secure Password Hashing with `bcrypt`
- Input validation and data normalization using `zod`
- Parameterized SQL queries to prevent SQL injection

### 🎯 Security Objectives Achieved

- ✔ Strong password hashing and secure credential storage
- ✔ Protection against brute-force attacks and credential-stuffing attacks
- ✔ Protection against Cross-Site Request Forgery (CSRF) attacks
- ✔ Mitigation of IPv6-based rate limit bypass techniques
- ✔ Prevention of SQL injection through parameterized database queries
- ✔ Strict input validation and data normalization
- ✔ Improved overall backend resilience against common web attacks
