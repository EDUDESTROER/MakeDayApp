# MakeDayApp

>A secure, full-stack productivity workspace focused on architecture, security hardening, and clean engineering practices.

MakeDayApp is a workspace platform that centralizes notes, tasks and project organization with a strong emphasis on security, backend resilience and manual validation logic to demonstrate engineering deph.

## 🚀 Live Project Status
⚠️ under active development


## Engineering Focus
this project was build to demonstrate
* Secure authetication flow
* Defensive backend design
* MVC-based structure
* security-first mindset
* Scalable backend architecture patters

## 🧩 Architecture Overview
### Backend
* Express.js server
* MVC architecture
* Layered validation
* Secure session management
* SQL database with parameterized queries
### Frontend
* Modular ES6 architecture
* Controller-based event orchestration
* Manual validation logic (no form libraries)
* DOM state management
* Dynamic note rendering

## 📚 Technical Stack

### Frontend

* Vanilla JavaScript (ES6 modules)
* EJS
* SCSS

### Backend

* Node.js
* Express
* Zod
* Bcrypt
* Express-rate-limit
* Redis

### Database

* SQL (Parameterized Queries)verall backend resilience against common web attacks
