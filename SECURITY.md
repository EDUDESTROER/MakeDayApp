# Security Policy

Only the latest version is supported with security updates.


| Version | Supported          |
| ------- | ------------------ |
|  main   |    ✅    |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

### ❌ Do not 
* Open a public GitHub issue.
* Discluse the vulnerability publicly it is reviewed

## ✅ Do
send a detailed report to: 
[eduardopicholi@hotmail.com](mailto:eduardopicholi@hotmail.com)


## What to include in Your Report
* A clear description of the vulnerability
* Steps to reproduce
* Expected vs Atual behavior
* Screenshots or logs (id applicable)
* Potential impact assessment (if known)
The more detailed the report, the faster it can be validated and addressed.

⏱ You can expect an initial response within a reasonable timeframe.
